# DocTranslate AI frontend

Initial Next.js App Router scaffold for OL1-B1. This project is intentionally
separate from the Vite prototype in the repository root; screen migration will
happen in a later wave.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run build
```
